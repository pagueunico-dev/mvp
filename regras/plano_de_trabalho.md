# Plano de Trabalho (Detalhado)

## MVP
Sistema web para consolidar contas e gerar boleto único.

## Stack
- Frontend: React
- Backend: Node.js (NestJS)
- DB: PostgreSQL
- Infra: Docker Compose

## Etapas detalhadas
1. Setup Docker (frontend + backend + db)
2. Modelagem:
   - Usuário
   - Contas
   - Pagamentos
3. Backend:
   - CRUD contas
   - Simulação pagamento
4. Frontend:
   - Dashboard
   - Lista de contas
5. Integração mock
6. Testes
